# Nexa AI Workspace

Build an AI-Powered Workplace Productivity Platform

Create a single integrated AI-powered workplace productivity web application called NEXA AI.

The purpose of the application is to help employees, students, managers, researchers, and business professionals automate common workplace tasks using AI.

This must be designed as ONE cohesive productivity platform/dashboard, NOT as separate websites or unrelated tools.

The platform should feel like a premium modern AI product similar to a futuristic SaaS productivity platform.

1. CORE CONCEPT

NEXA AI is an intelligent workplace productivity assistant that provides several AI-powered tools from one central dashboard.

The application must contain these core AI features:

Smart Email Generator

Meeting Notes Summarizer

AI Research Assistant

All features must exist inside the same application and use a consistent design system, navigation, branding, and user experience.

The AI should help users:

Write professional workplace emails

Summarize meetings and extract important information

Research and understand topics quickly

Generate useful insights and recommendations

Reduce repetitive administrative work

Improve workplace productivity

19. AI PROMPT ENGINEERING

Do not simply send raw user input to the AI.

Create structured prompts for each AI feature.

Email prompt structure

The AI should receive:

User context

Email purpose

Tone

Desired length

Recipient/context

Instruction:

"Generate a professional email based on the provided context. Do not invent facts, names, dates, commitments or information that the user did not provide. Maintain the requested tone. Return a clear subject and email body."

Meeting summarization prompt

The AI should:

Summarize only information contained in the notes

Identify decisions

Identify action items

Identify deadlines

Identify owners where explicitly stated

Never invent missing information

Research prompt

The AI should:

Clearly explain the topic

Separate facts from interpretation

Identify important insights

Provide recommendations where appropriate

Avoid fabricated references

Clearly state when information cannot be verified
